# Frequently Asked Questions

> This FAQ describes the project as documented in the repository. Confirm product and deployment details before presenting it as user-facing product information.

## What is Onoma AI Genesis?

The repository describes Onoma AI Genesis as an AI-oriented software project intended to bring together assistants, search, workspaces, agents, and automation. Some described capabilities may be planned, experimental, or conceptual rather than available features.

## Is it a live service?

The repository describes the project as early-stage development. Check the project's current release and deployment information; repository documentation alone does not promise that a hosted service is available.

## Is it patented or patent pending?

The README says no patent-pending claim is made unless a qualifying application has been filed. See [`PATENTS.md`](PATENTS.md); do not infer patent status from project descriptions.

## Can I copy, modify, or redistribute the code?

The README describes the project as proprietary. The repository currently has no standalone `LICENSE` file, so ask the project owner for written permission and authoritative terms before reuse. A public GitHub repository is not automatically open source. See [`COPYRIGHT.md`](COPYRIGHT.md).

## What happens to prompts, files, or account information?

That depends on the actual deployment and enabled integrations. [`PRIVACY.md`](PRIVACY.md) is a draft with required details still to be completed; do not submit real personal or confidential information to an experimental deployment until its data handling has been verified and disclosed.

## Does AI output always give correct answers?

No. Automated output can be inaccurate or incomplete. Verify important results independently before relying on them.

## How do I report a security issue?

Follow the private reporting instructions in [`SECURITY.md`](SECURITY.md). Do not post credentials, private user data, or sensitive vulnerability details in a public issue.

## Where can I send legal or privacy questions?

The project owner should add a monitored contact method to [`COPYRIGHT.md`](COPYRIGHT.md), [`PATENTS.md`](PATENTS.md), and [`PRIVACY.md`](PRIVACY.md) before publishing these documents as final policies.
